# Silk & Shape — Жуки-Ткачи

A mobile-first 2D browser game built with **HTML5 Canvas, CSS, and Vanilla JavaScript**. No external libraries or build step.

## Run locally
Open `index.html` in a modern browser. For the best mobile experience, open the deployed page on a phone in portrait orientation.

## Controls
- Tap a peg to rotate its direction arrow.
- Guide each glowing weaver bug along its own dashed silk route.
- Complete four patterns, with two-color patterns in the final levels.
- Use the ↻ button to restart the current level.

## Audio
Web Audio is initialized after pressing **ИГРАТЬ**, in response to the user's gesture. The game synthesizes pluck, snapped-string, and completion sounds locally.

## Deploy with GitHub Pages
In repository **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
