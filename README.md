# Silk & Shape — Жуки-Ткачи

A mobile-first 2D browser game built with **HTML5 Canvas, CSS, and Vanilla JavaScript**. No external libraries or build step.

## Visual direction
Warm craft-paper canvas, wooden peg buttons, tactile cotton/wool threads, and animated top-down bugs with six moving legs, eyes, and antennae.

## Five patterns
1. Heart — red weaver
2. House — red weaver
3. Ship — blue hull and red sail
4. Kitten — teal silhouette and red details
5. Butterfly — blue wings and red body

## Controls
- Tap any wooden peg to rotate its large direction arrow to the next connected peg.
- Arrows are visible across the whole pattern, so you can set upcoming turns before a bug arrives.
- Bugs move continuously. A strand only snaps when a bug reaches a peg and takes a connected strand of another color.
- Use the ↻ button to restart the current level.

## Run locally
Open `index.html` in a modern browser. For mobile, use portrait orientation.

## Audio
Web Audio starts after pressing **ИГРАТЬ**. Pluck, snap, and completion sounds are synthesized locally.

## Deploy with GitHub Pages
In repository **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
